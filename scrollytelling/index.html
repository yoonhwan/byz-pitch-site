음성 입력

PTT 버튼으로 마이크 활성화. VAD(음성 감지)로 발화 구간을 100ms 단위로 분리하여 전송.

📝

STT 변환

WebM/Opus 오디오를 LangGraph Node 1에서 텍스트로 실시간 변환. 부분 텍스트(stt.partial)가 스트리밍됩니다.

🌍

번역

Assemble(Node 2)로 텍스트 확정 후, Translate Fan-out(Node 3)에서 다국어로 동시 번역.

🇰🇷🇺🇸🇯🇵🇨🇳

다국어 분기

Polish(Node 4)로 번역 품질 향상 후 Redis Pub/Sub으로 각 참여자에게 해당 언어 번역 전달.

🔊

TTS 출력

번역된 텍스트를 TTS(Text-to-Speech)로 음성 합성하여 각 참여자의 언어로 재생.

👑 Host

호스트 · QR 생성

호스트가 방을 개설하고 QR 코드를 생성합니다. 게스트는 QR 스캔으로 참여합니다.

2
👑 Host 🇰🇷 KO 접속 중
👤 Guest 1 🇺🇸 EN 참여 중

게스트 join (순차 등장)

게스트가 순차적으로 방에 입장합니다. 각 참여자는 선호 언어를 설정합니다.

3
🔒 Host 발화 중
Guest 1, 2, 3 대기 중 PTT 해제 시 Lock 반환

발화자 전환 · Speaker Lock

한 명이 PTT를 누르면 Speaker Lock을 획득하여 독점 발언합니다. 해제 시 다음 발화자가 선택됩니다.

4
🇰🇷 KO 원문
🇰🇷 KO → 👑 Host
🇺🇸 EN → Guest 1
🇯🇵 JA → Guest 2
🇨🇳 ZH → Guest 3

다국어 동시 번역 분기

Translate Fan-out이 각 참여자의 언어로 동시 번역합니다. Redis Pub/Sub으로 각자에게 개인 번역이 전달됩니다.
